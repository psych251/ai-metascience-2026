# Psych 251 class metascience, Autumn 2026

Do best-practices extensions (rescues and upgrades) improve student replications? Opted-in
Psych 251 projects run a replication (Phase 1) and then a best-practices modification of it
(Phase 2). This repository holds the class-level plan, preregistration, analysis, and report.

- `writeup/metascience-2026.qmd` is the plan now, the preregistration before the first Phase 2
  launch, and the report afterwards. Render with `quarto render writeup/metascience-2026.qmd`
  (needs R with the tidyverse). Until project data are extracted, its results section runs on a
  simulated class and says so.
- `data/` (to come) will hold the extracted effects and replication ratings.

Prior work: Boyce, Mathur & Frank (2023, *RSOS*, doi:10.1098/rsos.231240) and Boyce et al. (2024,
*Collabra*, doi:10.1525/collabra.125685; code at
[langcog/251-rescue-projects](https://github.com/langcog/251-rescue-projects)).
